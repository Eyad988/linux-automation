# linux-automation

مجموعة سكربتات Bash لأتمتة المهام اليومية على لينكس.

---

## سكربت `Home-Organization`

### ماذا يفعل؟

يقوم السكربت بتنظيم الملفات الموجودة مباشرة في مجلد المنزل (`/home/blackdream`) ونقلها إلى مجلدات مخصّصة حسب نوع الملف:

| نوع الملف | الامتداد | المجلد الوجهة |
|-----------|----------|----------------|
| الصور | `.png` ، `.jpg` ، `.jpeg` | `~/Pictures` |
| صور أنظمة لينكس | `.iso` | `~/LinuxDistro` |
| أي ملف آخر | أي امتداد آخر | `~/OtherFiles` |

### كيف يعمل؟

1. **تعريف المسارات:** يحدّد في البداية مسار مجلد المنزل ومسارات المجلدات الثلاثة الوجهة.
2. **المرور على الملفات:** يمرّ بحلقة `for` على كل عنصر داخل مجلد المنزل.
3. **تجاهل المجلدات:** الشرط `[ -f "$file" ] || continue` يتخطّى أي عنصر ليس ملفًا عاديًا (مثل المجلدات)، فلا يتم نقل المجلدات.
4. **التعرّف على النوع:** يستخدم `case` مع `${file,,}` الذي يحوّل اسم الملف إلى أحرف صغيرة، لذلك يتعرّف على `PHOTO.JPG` و `photo.jpg` بنفس الطريقة.
5. **النقل الآمن:** يستخدم `mv -n` أي أنه **لا يستبدل** أي ملف موجود مسبقًا بنفس الاسم في المجلد الوجهة.
6. **الطباعة:** يطبع اسم كل ملف والمكان الذي نُقل إليه، مثل:
   ```
   wallpaper.png -> pictures
   archlinux.iso -> LinuxDistro
   notes.txt -> other
   ```
7. **الانتهاء:** يعرض رسالة `finish` داخل إطار عند الانتهاء.

### طريقة الاستخدام

```bash
chmod +x Home-Organization
./Home-Organization
```

### ملاحظات مهمة

- يجب أن تكون المجلدات `Pictures` و `LinuxDistro` و `OtherFiles` **موجودة مسبقًا**، لأن السكربت لا ينشئها. يمكن إنشاؤها بالأمر:
  ```bash
  mkdir -p ~/Pictures ~/LinuxDistro ~/OtherFiles
  ```
- مسار المنزل مكتوب بشكل ثابت (`/home/blackdream`)، لذلك إذا أردت استخدامه على جهاز آخر غيّر قيمة `HOME_DIR` أو استخدم `$HOME`.
- السكربت يتعامل فقط مع الملفات الموجودة مباشرة في مجلد المنزل، ولا يدخل إلى المجلدات الفرعية.
- الملفات المخفية (التي تبدأ بنقطة مثل `.bashrc`) **لا يتم نقلها**، لأن `*` في Bash لا تشمل الملفات المخفية افتراضيًا.

## إعدادات Claude Code (`claude-setup`)

ملفات تعرّف Claude Code على صاحب المستودع، وتضيف صيغ الفيديو حقته:

| الملف | الوظيفة |
|-------|---------|
| `claude-setup/CLAUDE.md` | ملف التعريف العام: من أنا، وكيف يرد عليّ، وقواعد الكود والفيديو |
| `claude-setup/skills/tech-explainer` | صيغة "الشرح التقني": فيديو قصير 25–30 ثانية بستايل النيون |
| `claude-setup/skills/deep-explanation` | صيغة "الشرح العميق": فكرة واحدة بعمق للمذاكرة |
| `claude-setup/install.sh` | ينسخ الملفات إلى `~/.claude/` ويتأكد من أدوات الفيديو |

### التثبيت

```bash
cd ~/linux-automation
git pull
bash claude-setup/install.sh
```

بعدها في أي مجلد شغّل `claude` واكتب مثلًا: "سوّ فيديو بالشرح التقني عن أمر grep".
